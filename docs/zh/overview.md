# 概览

baribari 是一款**本地优先**的会议实时转写 CLI。它在本机听音、标注说话人，把每次会议存成可重新打开的会话，并在你主动配置时，用 OpenAI 兼容 API 做纠错、翻译或总结。

## 你能得到什么

| 能力 | 含义 |
|------|------|
| **本地识别** | SenseVoice、Fun-ASR-Nano、ReazonSpeech 与 Silero VAD 均在本机运行 |
| **说话人** | 声纹标注每段发言，全局名册记住常客 |
| **会话** | 可回放、续录、修订、翻译、总结或共享 |
| **可选 AI** | 仅在你配置提供方后才调用纠错 / 翻译 / 总结 |
| **局域网共享** | 一台主机推送最终字幕，同伴用浏览器或 CLI 观看 |
| **终端界面** | 一个专注的 TUI 集中显示字幕、说话人、设备、录音与状态 |

## 数据流

```text
麦克风 / 系统声  →  VAD  →  ASR  →  说话人  →  本地润色
                                         ↘ 可选 AI
                                         ↘ 会话文件
                                         ↘ 局域网共享（仅最终句）
```

字幕在 **VAD 切出一段语音之后** 出现，而不是逐词流式。解码中可能显示实时状态行；**只有最终句**会写入文件、共享或送去 AI。
