# ロードマップメモ

現在の製品と開発の優先順位を示す資料です。リリース時期や実装を確約するものではありません。

## P0

- 長時間録音を WAV ファイルへ逐次書き込み、メモリ使用量を抑える
- 実行中に異常終了したセッションを復旧する
- Linux/macOS の録音対応と説明を改善する
- セッションパス、音声結合、再生位置移動のテストを追加する

## P1

- SRT、VTT、Markdown、JSON への書き出し
- 話者の改名、統合、名簿操作を改善する（一部実装済み）
- **partial 表示と任意の online zipformer** による低遅延字幕
- Resume モードの全文検索と、該当時刻への移動
- 分かりやすいセッション名と一覧表示

## P1.5

- 長い発話区間内で話者の変化点を検出する
- `mixed` や不確実な話者ラベルを追加し、手動修正を改善する
- 会議後に offline diarization を実行して話者ラベルを付け直す

## P2

LAN 認証 · headless · `--engine-cmd` · 差し替え可能 ASR

## P3

同通 TTS→仮想マイク · 字幕オーバーレイ · プライバシーモード

## 近い非目標

クラウドのみの既定 · 非商用 diar の既定同梱 · 分離なしの完璧な重なり分解
