# 概要

baribari は**ローカル優先**の会議リアルタイム文字起こし CLI です。端末上で音声を聞き、話者をラベル付けし、会議を再開できるセッションとして保存します。必要なら、自分で設定した OpenAI 互換 API で訂正・翻訳・要約も行えます。

## できること

| 機能 | 意味 |
|------|------|
| **ローカル ASR** | SenseVoice、Fun-ASR-Nano、ReazonSpeech、Silero VAD が端末上で動作 |
| **話者** | 埋め込みで発話をラベル付け。グローバル名簿が常連を記憶 |
| **セッション** | 再生、続行、訂正、翻訳、要約、共有が可能 |
| **任意の AI** | プロバイダを設定したときだけ訂正 / 翻訳 / 要約 |
| **LAN 共有** | 1 台のホストが確定字幕を配信。閲覧側はブラウザまたは CLI |
| **ターミナル UI** | 字幕・話者・デバイス・録音・状態を 1 つの TUI に集約 |

## データの流れ

```text
mic / loopback  →  VAD  →  ASR  →  話者 ID  →  ローカル整形
                                         ↘ 任意の AI
                                         ↘ セッションファイル
                                         ↘ LAN 共有（確定のみ）
```

字幕は**VAD が発話区間を切ったあと**に出ます（単語ごとのストリーミングではありません）。デコード中はライブ状態行が出ることがあり、**確定文だけ**が保存・共有・AI に送られます。
