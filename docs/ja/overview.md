# 概要

baribari は、**会議から始まるローカル音声ワークスペース**です。現在は端末上で音声を認識し、話者をラベル付けし、再開できるセッションとして保存します。同じ基盤を、検索可能な会議知識、Headless チーム共有、翻訳音声、会話練習へ育てています。

約束はシンプルです。**会話を今理解し、文脈を後から活用でき、音声の主導権を常に手元に残すこと。**

## できること

| 機能 | 意味 |
|------|------|
| **ローカル ASR** | SenseVoice、Fun-ASR-Nano、ReazonSpeech、Silero VAD が端末上で動作 |
| **話者** | 埋め込みで発話をラベル付け。グローバル名簿が常連を記憶 |
| **セッション** | 再生、続行、訂正、翻訳、要約、共有が可能 |
| **任意の AI** | プロバイダを設定したときだけ訂正 / 翻訳 / 要約 |
| **LAN 共有** | 1 台のホストが確定字幕を配信。閲覧側はブラウザまたは CLI |
| **集中クライアント** | 字幕・話者・デバイス・録音・状態を 1 つの TUI に集約 |

## これから向かう場所

| レイヤー | 方向 |
|----------|------|
| **今理解する** | 低遅延字幕、日本語認識、確信度を正直に示す話者ラベル |
| **後から覚える** | 検索、編集、出力、再処理、永続的な会議文脈 |
| **安全に共有する** | ブラウザ、API、自動化へ配信するセルフホストエンジン |
| **音声で行動する** | 翻訳音声、字幕オーバーレイ、発音コーチングの実験 |

[ロードマップ](./roadmap) は確定した優先度と実験を分け、将来像を現時点の機能として誤解させないようにします。

## データの流れ

```text
mic / loopback  →  VAD  →  ASR  →  話者 ID  →  ローカル整形
                                         ↘ 任意の AI
                                         ↘ セッションファイル
                                         ↘ LAN 共有（確定のみ）
```

字幕は**VAD が発話区間を切ったあと**に出ます（単語ごとのストリーミングではありません）。デコード中はライブ状態行が出ることがあり、**確定文だけ**が保存・共有・AI に送られます。
