baribari 是一套**从会议开始的本地语音工作空间**。现在，它在本机听音、标注说话人，并把会议保存成可重新打开的会话；同一套底座正在向可搜索的会议知识、Headless 团队共享、翻译语音和口语练习扩展。

核心承诺很简单：**当下听懂对话，之后继续利用上下文，并始终保留对音频的控制。**

## 你能得到什么

| 能力 | 含义 |
|------|------|
| **本地识别** | SenseVoice、Fun-ASR-Nano、ReazonSpeech 与 Silero VAD 均在本机运行 |
| **说话人** | 声纹标注每段发言，全局名册记住常客 |
| **会话** | 可回放、续录、修订、翻译、总结或共享 |
| **可选 AI** | 仅在你配置提供方后才调用纠错 / 翻译 / 总结 |
| **局域网共享** | 一台主机推送最终字幕，同伴用浏览器或 CLI 观看 |
| **专注客户端** | 一个 TUI 集中显示字幕、说话人、设备、录音与状态 |

## 接下来会走向哪里

| 层次 | 方向 |
|------|------|
| **当下理解** | 更低延迟字幕、更好的日语识别、诚实表达置信度的说话人标注 |
| **之后记得** | 搜索、编辑、导出、重新处理和持久会议上下文 |
| **安全共享** | 一套自部署引擎服务浏览器、API 与自动化 |
| **用语音行动** | 翻译语音、悬浮字幕和发音指导实验 |

[路线图](/baribari/wiki/zh/project/roadmap) 会明确区分确定优先级与实验方向，避免把未来方向误解为已经存在的功能。

## 数据流

```text
麦克风 / 系统声  →  VAD  →  ASR  →  说话人  →  本地润色
                                         ↘ 可选 AI
                                         ↘ 会话文件
                                         ↘ 局域网共享（仅最终句）
```

字幕在 **VAD 切出一段语音之后** 出现，而不是逐词流式。解码中可能显示实时状态行；**只有最终句**会写入文件、共享或送去 AI。
